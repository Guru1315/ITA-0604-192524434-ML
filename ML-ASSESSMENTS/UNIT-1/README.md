# Unit 1 assessments

Three assessment tools for Unit 1 of the Machine Learning course (ITA 0604). Assessment Tool 1 names the course outcome it covers as CO1: concept learning, version spaces and Candidate Elimination, inductive bias and decision tree learning.

| Folder | Document | What it is |
|---|---|---|
| [`ASSESSMENT TOOL 1`](ASSESSMENT%20TOOL%201/README.md) | `CO1-AT1-ML.docx` | 15 application-based questions (Bayes' theorem, metrics, overfitting) |
| [`ASSESSMENT TOOL 2`](ASSESSMENT%20TOOL%202/README.md) | `CO_AT_2_Concept_Map_Humanized.docx` | 15 concept maps, each in a different style |
| [`ASSESSMENT TOOL 3`](ASSESSMENT%20TOOL%203/README.md) | `Performance-Analysis-and-Merit-of-a-Machine-Learning-System.pdf` | 8-page deck on evaluating a machine learning system |
