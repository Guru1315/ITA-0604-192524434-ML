Fifteen scenario questions with worked answers. Each answer is organised under assessment-criteria headings such as conceptual understanding, accuracy of answer and application of knowledge, with a step-by-step calculation where one is needed. By topic:

| Topic | Questions |
|---|---|
| Probability with Bayes' theorem (coloured balls in boxes, defective items) | 1, 2, 11, 12 |
| Classification metrics for a medical image model | 3, 14 |
| Spotting overfitting from loss and accuracy values | 4, 5 |
| Generalisation and regularisation | 6, 15 |
| Applying classification to real settings (tires, disease detection, spam email, quality inspection) | 7, 8, 9, 10 |
| Metrics for a deep learning model with KNN | 13 |

The course outcome named on the cover also covers concept learning and decision trees, which are implemented in code in the [lab experiments](../../../LAB%20EXPERIMENTS/README.md) (EXP 1 to 4).
