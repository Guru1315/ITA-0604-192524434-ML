Coursework for **ITA 0604, Machine Learning** at SIMATS Engineering (Saveetha University): lab experiments, unit assessments, an SDG assignment and capstone material.

## 🚀 Repository overview

| Folder | Contents | Status |
|---|---|---|
| [`LAB EXPERIMENTS`](LAB%20EXPERIMENTS/README.md) | Ten experiments: Find-S, Candidate Elimination, ID3, decision trees, perceptrons, backpropagation, an MLP, MNIST and a genetic algorithm | ✅ Complete |
| [`ML-ASSESSMENTS/UNIT-1`](ML-ASSESSMENTS/UNIT-1/README.md) | Three assessment tools: application questions, 15 concept maps and a deck on evaluating ML systems | ✅ Added |
| `ML-ASSESSMENTS/UNIT-2` to `UNIT-5` | Assessments for the later units | ⏳ Coming soon |
| [`SDG ASSIGNMENT`](SDG%20ASSIGNMENT/README.md) | Report and code on predicting employment trends with ML (SDG 8), using simulated data | ✅ Added |
| `CAPSTONE PROJECTS` | Capstone presentation, one-page write-up and report | ⏳ Planned |

## 🧠 Topics covered

- **Concept learning:** Find-S, Candidate Elimination and version spaces
- **Decision trees:** built by hand with ID3 and with scikit-learn
- **Neural networks:** a perceptron, backpropagation on XOR, an MLP and a Keras network for MNIST
- **Evolutionary search:** a genetic algorithm
- **Evaluation:** accuracy, precision, recall, F1-score, confusion matrices, ROC curves and baselines
- **Applied analysis:** data cleaning, time-based validation and forecasting on a simulated labour-market dataset

## 📓 Using the notebooks

Open a notebook in Google Colab or Jupyter. Each experiment folder explains what it needs, and the datasets it uses are stored beside the notebook.

> 💡 For the labs that rely on local CSV files, keep the data file in the same folder as the notebook.

## 🧾 Notes

These are student coursework files. The datasets used in the labs are small teaching examples, and the SDG assignment uses simulated data, so none of the results should be read as findings about real labour markets or real-world employment patterns.
